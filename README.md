# All the Skills: Python Learning Archive

This repository started as a small college-era Python practice repo. It now keeps that original learning trail intact while turning the project into a cleaner public archive for Python basics, Django Girls notes, and AI-assisted study experiments.

## What is here

- `djangogirls/MeFirstPython.py` keeps the original beginner script as a snapshot of the first exercises.
- `docs/` contains the GitHub Pages site for the repository.
- `.gitignore` keeps local virtual environments, caches, and generated files out of version control.

## Why revive it

The purpose is still the same: learn by writing small Python programs. The new layer adds structure around the old work so the repository is easier to read on GitHub and easier to grow over time.

The revival is intentionally honest:

- preserve the old code instead of hiding it
- explain what the early script was practicing
- add modern notes and examples gradually
- use AI as a study partner for explanations, refactors, and project ideas

## Run the legacy exercise

The original script asks for input from the terminal:

```bash
python3 djangogirls/MeFirstPython.py
```

It includes early examples of:

- printing values
- defining functions
- reading input
- using `if` statements
- looping through lists
- appending user-provided values

## GitHub Pages

The public site lives in `docs/`.

To deploy it on GitHub:

1. Open the repository settings.
2. Go to **Pages**.
3. Set the source to **Deploy from a branch**.
4. Select `master` and `/docs`.
5. Save.

After GitHub builds it, the site should be available at:

```text
https://jovylle.github.io/all-the-skills-python/
```
