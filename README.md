## What is here

- `djangogirls/MeFirstPython.py` — first Python exercises (print, lists, functions, input, conditionals, loops).
- `docs/` — GitHub Pages site for this repository.
- `.gitignore` — keeps local virtual environments, caches, and generated files out of version control.

## Run the exercise

```bash
python3 djangogirls/MeFirstPython.py
```

The script uses terminal input and covers:

- printing values
- defining functions
- reading input
- using `if` statements
- looping through lists
- appending user-provided values
